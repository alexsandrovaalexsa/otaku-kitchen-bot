# 🍡 Otaku Kitchen Bot

Бесплатный бот-каталог рецептов для публичного канала [@otakukitchen](https://t.me/otakukitchen).

## Что умеет

- 🥞 Категории: завтраки, обеды, ужины, десерты, напитки.
- 🔎 Поиск по нескольким продуктам, например `курица, рис, яйца` **или** `курица рис яйца` (пробелы без запятых тоже работают).
- 🛒 Показывает ингредиенты, которых нет в указанном списке, и количества **по исходному посту**.
- 🎬 Поиск по названию аниме.
- 📖 Кнопки ведут прямо на оригинальные посты канала.
- 🆕 Новые публикации с хэштегами подхватывает автоматически, если бот добавлен администратором канала и хостинг сохраняет файл `recipes.json`.

Не требуется платный AI/API. Реализация на стандартной библиотеке Python, без `pip install`.

## Запуск на Windows — для @otakukitchen_recipes_bot

1. Установите Python 3.10+ с [python.org](https://www.python.org/downloads/windows/) (включите **Add Python to PATH**).
2. Распакуйте ZIP в обычную папку на компьютере.
3. Дважды нажмите **`START_BOT_WINDOWS.bat`** внутри папки.
4. Когда появится запрос, вставьте токен, присланный [@BotFather](https://t.me/BotFather). Символы не будут видны: это нормально. Нажмите Enter. Токен не сохраняется в файлы и **не должен отправляться в чат**.
5. Откройте [@otakukitchen_recipes_bot](https://t.me/otakukitchen_recipes_bot) и нажмите **Start**.

Если предпочитаете запуск вручную, откройте PowerShell в папке проекта и выполните:

```powershell
$env:BOT_TOKEN="ВАШ_ТОКЕН_ОТ_BOTFATHER"
py bot.py
```

Закрытие окна остановит бота. Это способ локально протестировать его, а не круглосуточный хостинг.


Бот работает, пока этот процесс запущен и компьютер включён. Для круглосуточной работы понадобится размещение в постоянно активном процессе/сервере. Бесплатные тарифы хостингов могут засыпать, прерывать фоновый polling и терять локальные файлы. Для надёжной автоматической синхронизации нужна постоянная папка/база данных.

## Обновление старых рецептов из экспорта

Экспортируйте Telegram Desktop → «Экспорт истории чата» → JSON. Сохраните рядом с папкой `result.json`, затем:

```powershell
py catalog.py ..\result.json recipes.json
```

**Внимание:** эта команда заменяет файл `recipes.json` на данные из экспорта. Лучше сначала создать его резервную копию. Новые посты также автоматически добавляются (см. ниже).

## Как получать новые рецепты автоматически

В управлении каналом `@otakukitchen` добавьте своего бота **администратором**. Тогда Telegram Bot API будет отправлять ему события `channel_post` и `edited_channel_post`, а код будет автоматически добавлять и обновлять публикации с хэштегами категорий. Экспорт нужен **для старых** публикаций, новые доступны через события Bot API.

Требуется, чтобы была возможность записывать `recipes.json` и чтобы файл сохранялся между перезапусками. На эфемерных бесплатных сервисах изменения могут пропадать — для такого размещения следует использовать постоянную БД, диск или повторную сборку каталога.

## Важные ограничения текущего прототипа

- Список наличия указывается **без количеств**. Бот проверяет наличие названия продукта, но не то, сколько его осталось. Для точного расчёта граммов нужны введённые пользователем остатки и конвертация единиц.
- Вода, соль и чёрный перец по умолчанию считаются обычными продуктами и не добавляются в список покупок; правило можно изменить в `search_engine.py` (`PANTRY`).
- Ингредиенты извлечены автоматически из авторских постов. Разделы разного формата, в том числе юмористические, могут потребовать ручной проверки. В `recipes.json` доступна метка `needs_review` — такие записи не показываются в боте до проверки.
- В экспорте есть **284 публикации с хэштегами категорий**, из которых одна шуточная («Легендарная вода»). Несколько рецептов без категорий не импортированы: необходимо добавить хэштеги в канал или включить отдельно.
- Группы «обед» и «ужин» пересекаются: один рецепт может присутствовать в нескольких разделах.
- Мультиязычный/неоднозначный ввод и альтернативы типа «моцарелла/чеддер» обрабатываются простыми правилами. Это прототип, а не гарантированно точная система подбора.

## Файлы

- `recipes.json` — готовый каталог с ID, названием, URL оригинального поста, категориями, тегами, ингредиентами и количествами.
- `catalog.py` — парсер исходного Telegram Desktop JSON и функция разбора новых постов.
- `search_engine.py` — сопоставление продуктов/рецептов и расчёт списка покупок.
- `bot.py` — Telegram-бот, long polling.

## Если уже запущена старая версия

1. Закройте чёрное окно с ботом.
2. Распакуйте обновлённый архив в **новую** папку.
3. Запустите `START_BOT_WINDOWS.bat`, вставьте токен от @BotFather.
4. В Telegram нажмите «Новый поиск» и отправьте `молоко мука яйца`.

Исправление: ввод через пробел разбивается на отдельные продукты, а известные составные названия («сливочное масло», «томатная паста») не разделяются. В результатах теперь выводятся названия найденных продуктов, а не только число.
