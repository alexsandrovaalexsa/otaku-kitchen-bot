# 🍡 Otaku Kitchen: бесплатный хостинг на Render

Уже готовы: `bot.py`, `search_engine.py`, `catalog.py`, `recipes.json` и **`webhook.py`** — последняя версия для размещения на бесплатном Render. Скрипт `bot.py` на Windows по-прежнему работает через опрос Telegram; **для хостинга запускаем именно `webhook.py`**.

## 1. Сначала остановите бот на Windows

Закройте чёрное окно `START_BOT_WINDOWS.bat`. Если его оставить открытым, одновременно с webhook будут приходить ошибки получения обновлений.

## 2. Загрузите код на GitHub

1. Откройте https://github.com и войдите/зарегистрируйтесь.
2. Нажмите **+ → New repository**. Название: `otaku-kitchen-bot`. Выберите **Private** или **Public**. **Не добавляйте токен в репозиторий!**
3. В пустом репозитории нажмите **uploading an existing file** (или **Add file → Upload files**).
4. Перетащите из распакованной папки **все файлы** этого проекта, включая `webhook.py`, `recipes.json` и `render.yaml` (не сам ZIP). Если скрытый `.gitignore` не загружается, это не страшно.
5. Нажмите **Commit changes**.

## 3. Создайте бесплатный Web Service в Render

1. Откройте https://dashboard.render.com и войдите через GitHub или зарегистрируйтесь.
2. Выберите **New → Web Service → Git Provider** и подключите GitHub, если потребуется.
3. Выберите репозиторий `otaku-kitchen-bot`.
4. Настройки: **Language: Python**, **Plan: Free**, **Build Command:** `python -m compileall -q .`, **Start Command:** `python webhook.py`.
5. Найдите раздел **Environment Variables** / **Environment**. Добавьте ключ `BOT_TOKEN`, а в значение вставьте секретный токен из `@BotFather`. **Токен вводится только в защищённые переменные Render. Никогда не сохраняйте его в файлах GitHub и не отправляйте в чат!**
6. Нажмите **Deploy Web Service**. Render сам задаёт `RENDER_EXTERNAL_URL` — адрес сайта, по которому Telegram отправляет сообщения боту. Программа автоматически зарегистрирует защищённый webhook.

## 4. Проверьте

- В Render откройте вкладку **Logs**. Должно появиться `Listening on port ...` и `Webhook configured: https://...onrender.com/telegram`.
- Откройте `https://t.me/otakukitchen_recipes_bot` и отправьте `/start`.
- Проверьте категорию и поиск `молоко мука яйца`.
- **Проверяйте без запуска Windows-версии**, иначе могут быть конфликты polling/webhook.

## Ограничения бесплатного Render

- После примерно 15 минут без веб-запросов Render приостанавливает сервис; следующее сообщение может разбудить его с задержкой в минуту или дольше. Telegram обычно повторяет webhook при неуспешной доставке, но **мгновенные ответы и 100% бесперебойность не гарантируются**.
- Включённый в проект **каталог `recipes.json` будет доступен после перезапуска**, так как он часть репозитория.
- **Новые посты**, полученные после запуска и добавленные ботом в `recipes.json` на самом сервере, **не сохраняются между перезапусками или засыпанием бесплатного Render**. Чтобы обновить каталог надёжно, нужно периодически экспортировать канал и заменять `recipes.json` в GitHub или подключить постоянную бесплатную внешнюю базу (дополнительный этап).
- История поиска пользователя хранится в памяти, поэтому после долгого перерыва или засыпания нужно начать новый поиск. Для полноценного сохранения нужны дополнительные механизмы.
- Бесплатный тариф имеет квоты, при превышении которых сервис могут приостановить. При отсутствии платёжного метода Render не должен начать списывать деньги автоматически.

## Важно, если решите снова запустить бота на компьютере

Telegram не разрешает использовать `getUpdates` параллельно с активным webhook. Чтобы вернуться к Windows-версии, сначала остановите Render Web Service или удалите webhook через Telegram API (токен никому не показывайте). Для обычного использования на Render компьютер не нужен.
